# collective

The Hameeda Hossain Collective — https://hameedahossain.github.io/collective/

An archive of the writings, interviews and public life of Hameeda Hossain. The site is plain HTML served by GitHub Pages from the `main` branch.

## How the site is made

The pages are generated by one script from simple data files, so you never edit page HTML by hand.

| What | Where |
|---|---|
| Her writings (full text, one file each) | `_content/writings/*.md` |
| Newspaper articles (PDF scans) | `_data/articles.json` + files in `articles/` |
| Interviews | `_data/interviews.json` (+ `_data/interviews_added.json`) + files in `interviews/` |
| Magazines | `_data/magazines.json` + files in `magazines/` |
| Books (with buy links) | `_data/books.json` |
| About text, home intro, portrait, milestones | `_data/about.json` |
| Design | `assets/site.css`, `assets/site.js` |

Folders that start with `_` are not published.

## Updating

1. Edit or add the data / content file (copy an existing entry as a template).
2. Rebuild the pages: `python3 _build/build.py`
3. Commit and push.

To preview locally: `python3 -m http.server 8765`, then open http://localhost:8765.
